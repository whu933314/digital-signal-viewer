## 0. 這份文件是什麼、怎麼用

這是 Digital Signal Viewer（DSV）**現有功能的完整清單**。使用者 2026-11-01 的要求：
「最重要的是不能因為改版，已經有的功能就壞掉不能用或不見，所以請把有的功能都記錄下來；另外每次改版完都要把新增的功能詳細寫下來。」
一個沒有任何記憶的新 session 要靠這份文件知道 DSV 有哪些功能、每一項怎麼操作、預期行為是什麼，並在改版前後逐條確認沒有少、沒有壞。

- **改版前後都要逐條核對**：深度檢查（「DSV 深度測試」）的回歸驗證者拿這份清單逐條確認；每一條都寫了怎麼操作、預期行為、對應的 GUI 測試步驟代號（`tests_gui_mac.py` 的 `sNN_…`、`tests_plotkit_gui_mac.py` 的 `pk-sNN`、`tests_i18n_mac.py` 的 `i18n-sNN`），沒有測試的寫「無→待補」。
- **改版後**：新增或改變的功能加進對應的區段、標上版本；同時在 `docs/CHANGELOG.md` 寫一節「這版新增了什麼」。
- **配套文件**：`docs/CHANGELOG.md`（每版新增什麼）、`audit/DEEP_TEST_HANDBOOK.md`（深度檢查怎麼跑；`audit/` 只在本機，不上 GitHub）、
  `audit/tools/inventory_baseline_1.0.0.json`（`audit/tools/inventory_dsv.py` 在 1.0.0 乾淨複本上跑出來的機器可比對基準；0.9.14 的 `inventory_baseline_0.9.14.json` 保留：
  106 個動作、8 個工具列分頁／33 個區段／195 個控制項、11 顆圖工具列按鈕、80 個訊號屬性面板控制項、6 個停靠面板、27 個右鍵／下拉選單站點（含子選單共 919 個項目）、8 個檔案對話框、Tk 綁定與類別綁定；
  用 `audit/tools/inventory_diff.py` 和新版的輸出 diff；1.0.0 對 0.9.14 只差版本字、檢視 ▸ 外觀 主題下拉的選項／工具提示／寬度，都是決定過的）。
- 標記：**★ 使用者特別要求**＝使用者親口回報、多次提醒或用選單決定過的行為，改掉就是回歸；（）裡的「第 N 項」＝使用者回報問題清單的編號（1～13）、「U*n*」＝第 10～12 項期間的使用者決定（U1～U16）、「B*n*」＝0.9.13 的資料安全決定、「W*n*」＝Windows 相容性項目。
- 「首次版本」欄：`v3.4 以前`＝v3.2～v3.4（2026-10-22 以前）就有；`0.9.1 以前`＝2026-10-23 當天的改動（工具缺口批次 A～E、資料夾面板、快速鍵系統、panel 握把、AM/PM/FM 視窗、拖放…，當天晚上才開始用 x.y.z 版號）；其餘寫版號。
- 本文件沒有個人資料、沒有 MATLAB 原始碼；位置都用「使用者家目錄」「`%LOCALAPPDATA%\SignalViewer`」這種寫法。

## 4. 維護規則（每次改版）

1. **改版前／合併後**：回歸驗證者照本文件第 1 節逐條驗、第 2 節逐區抽驗（至少每區每個 ★ 項目），並跑 2.14 的五套；功能盤點 `inventory_dsv.py` 跑在新版乾淨複本上，和上一版的基準（目前 `audit/tools/inventory_baseline_1.0.0.json`）diff——少了任何動作、選單項目、按鈕、面板都是回歸，除非能對到使用者的決定。
2. **發布後**：把新增／改變的功能加進第 2 節對應區段、標上版本與測試代號；第 1 節有新的「使用者特別要求」就加 ★；第 3 節更新已知問題；同時在 `docs/CHANGELOG.md` 寫一節（版本、日期、新增、改變、修正、已知）；更新本文件開頭的版本與 commit 短碼。
3. **重跑盤點**：`inventory_dsv.py -o audit/tools/inventory_baseline_<新版本>.json`，保留舊基準不刪，diff 的結果寫進 CHANGELOG。
4. **行為改變的合法性**：只有使用者決定涵蓋的改變才算合法（決定檔在本機 `audit/` 資料夾；使用者過去的原話優先），否則就是回歸；有衝突先提醒使用者、用選單決定（使用者 2026-10-25 要求「這些改動不能違背我之前所有提的要求，有的話要提醒我」）。
5. **測試**：每個新功能與每個使用者回報的行為都要有 GUI 測試擋住（走真的 Tk 事件／按鍵路徑），放進 `tests_gui_mac.py` 並確認兩半都跑到；改右鍵選單、版面、拖放、分析視窗時先跑 N1～N4 對應的步驟。
6. **文件**：README 中英同步、台灣用語；本文件沒有個人資料。
